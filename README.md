# CLI Search Tool

A lightweight command-line utility written in Rust that searches for a specified pattern (substring) within a file and prints out any matching lines, functioning similarly to a basic `grep` command.

## Usage

Run the program using Cargo by passing your search pattern followed by the path to the target file:

```bash
cargo run -- "<pattern>" <path/to/file>

```

### Example

```bash
cargo run -- "fn main" src/main.rs

```

## Dependencies

* **[clap](https://crates.io/crates/clap)** (`v4+`): Industry-standard command-line argument parser utilizing derive macros.
* **[anyhow](https://crates.io/crates/anyhow)**: Provides flexible, idiomatic error handling with rich context propagation.

## Code Walkthrough & Concepts Explained

This program demonstrates several key Rust paradigms, standard library utilities, and ecosystem conventions.

### 1. Command-Line Argument Parsing (`clap`)

```rust
#[derive(Parser)]
struct Cli {
	/// The pattern to look for
	pattern: String,
	/// The path to the file to read
	path: std::path::PathBuf,
}

```

* **`#[derive(Parser)]`**: A procedural macro provided by `clap`. It automatically generates the boilerplate code required to parse command-line arguments, handle user input validation, and generate `--help` and `--version` flags based on the structure definition.
* **Doc Comments (`///`)**: `clap` automatically reads doc comments above struct fields and turns them into descriptions for command-line help outputs.
* **`std::path::PathBuf`**: An owned, mutable path type (equivalent to how `String` relates to `&str`). Using `PathBuf` instead of a raw `String` for file paths ensures cross-platform compatibility, correctly handling path separators across Windows (`\`) and Unix (`/`) systems.

### 2. Execution and Error Handling (`anyhow`)

```rust
fn main() -> Result<()> {
	let args = Cli::parse();
	
	let content = std::fs::read_to_string(&args.path)
	.with_context(|| format!("could not read file `{}`", args.path.display()))?;
	// ...
	Ok(())
}

```

* **`Cli::parse()`**: Executes the argument parser generated by `clap`, capturing inputs from `std::env::args()` and mapping them into the `Cli` struct fields.
* **`anyhow::Result<()>`**: A convenient type alias for `Result<(), anyhow::Error>`. Instead of dealing with custom, verbose error types for every library or operation, `anyhow` allows functions to return a unified error type that can wrap any error implementing `std::error::Error`.
* **`std::fs::read_to_string()`**: A standard library function that opens the file at the given path, reads its entire contents into memory, and returns it as a heap-allocated `String`.
* **`with_context(|| ...)`**: A method from the `anyhow::Context` trait. If `read_to_string` fails (e.g., file not found or permission denied), `with_context` attaches additional human-readable context to the error. It uses a closure (`|| ...`) so the formatting string is *only* evaluated if an error actually occurs, avoiding unnecessary overhead.
* **The `?` Operator**: A shorthand operator used to propagate errors. If the expression succeeds, it unwraps the inner value (`String`). If it fails, it immediately returns the error (wrapped in `anyhow`) out of the `main` function.
* **`anyhow::Ok(())`**: A convenience helper from the `anyhow` crate used to cleanly wrap the successful unit return value (`()`) matching the function's `Result<()>` signature.

### 3. String Processing and Iteration

```rust
for line in content.lines() {
	if line.contains(&args.pattern) {
		println!("{}", line);
	}
}

```

* **`content.lines()`**: Returns an iterator over the lines of the file string. It efficiently handles different newline conventions automatically (both Unix `\n` and Windows `\r\n`) without creating unnecessary owned string allocations for every line.
* **`line.contains(&args.pattern)`**: A standard string slice method that checks if the string slice (`&str`) contains the specified substring pattern.
* **`println!("{}", line)`**: A macro used for formatted text output, printing matching lines directly to the standard output stream.
